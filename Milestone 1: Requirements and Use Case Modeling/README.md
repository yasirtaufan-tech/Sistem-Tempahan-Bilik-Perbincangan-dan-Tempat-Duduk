Report Structure Elements

1. Project Background 

1.1 Problem Statement and Justification 
Problems to solve. 

1.2 Proposed System Overview
Brief description of the system that is being proposed.

1.3 Project Planning (Roles, GitHub & Timeline) 
Description of the roles and responsibilities of different team members.
Include a picture and a brief biography of each team member. 
GitHub activity details.

2. System Requirements

2.1 2.2 Stakeholder Identification & Requirement Gathering Functional Requirements
List of all functional requirements. Functional requirements define the fundamental actions 
that must take place in the software in accepting and processing the inputs
and in processing and generating the outputs. 

2.3 Non-Functional Requirements 
List of all non-functional requirements with their description in a table form.
